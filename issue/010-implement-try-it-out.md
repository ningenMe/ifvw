# Try it out機能を実装する

関連: #1 (concept), #008

## 背景

OpenAPIの情報を利用して、実際にAPIリクエストを送信できるようにする(Swagger UIの「Try it out」相当)。

## やること

- API詳細画面にリクエストパラメータ/request bodyの入力フォームを追加する
- 入力内容から実際のHTTPリクエストを組み立て、対象サービスへ送信する
- レスポンス(status code / headers / body)を表示する
- CORSなどブラウザから直接叩けない場合の扱いを検討する(必要であればサーバー側でproxyする)

## 完了条件

- 実際のAPIエンドポイントに対してリクエストを送信し、レスポンスを画面上で確認できる
