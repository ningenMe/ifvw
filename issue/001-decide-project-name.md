# プロジェクト名を決定する

関連: #1 (concept)

## 背景

現状「ifvw」は仮のリポジトリ名で、プロダクトとしての正式名称が決まっていない。
以降のリポジトリ構成・README・CLIコマンド名(例: `npx <name> generate`)などに影響するため、最初に決める必要がある。

## やること

- プロダクトコンセプト(「複数のマイクロサービスのAPI仕様を、1つのUIで横断して探索できるAPI Explorer」)に合う名前の候補を出す
- 名前を決定する
- READMEにプロダクト名とコンセプトの一言説明を記載する

## 完了条件

- README.md にプロジェクト名とコンセプトが記載されている
